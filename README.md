# DBSDV Collection

ドラゴンボールスーパーダイバーズのカードコレクション管理アプリです。

## 主な機能

- カード検索
- 所持カード管理
- コレクション進捗表示
- デッキ作成
- Excelインポート
- バックアップ・復元

## 公開サイト

https://dbsdv.github.io/dbsdv-collection/

## 開発環境

- HTML
- CSS
- JavaScript
- Node.js
- Express
- Playwright
- Sharp
